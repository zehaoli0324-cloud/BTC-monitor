# BTC 交易决策系统 v7

一个功能全面的比特币实时交易决策仪表板。纯前端 HTML，浏览器打开即用，无需后端。

在线体验：直接下载 `btc_analysis_v7.html` 用浏览器打开即可。

---

## 功能概览

### 📊 实时行情看板
- **多源行情 API**：自动从 OKX（主源）和 Binance（备用）获取 BTC-USDT 实时价格
- **衍生品数据**：资金费率、未平仓合约量（OI）、多空比（LSR）
- **恐贪指数（FGI）**：来自 alternative.me 的恐惧与贪婪指数
- **自动刷新**：每 30 秒自动更新所有数据

### 🚨 单边行情爆发概率预警（5分钟内）
- **6 因子加权模型**：布林带收缩、ATR 扩张/收缩、量能放大、ADX 趋势强度、动量加速、K 线同向性
- **市场状态机（5 种）**：爆发单边 / 平稳单边 / 高波洗盘 / 波动率压缩蓄力 / 低波积累
- **状态自适应调节系数**：不同市场状态有不同的爆发概率调节因子
- **Logistic 映射校准**：原始分数经 sigmoid 映射到 0-100% 概率区间

### 🎲 多空概率计算器
- **7 因子加权系统**：
  1. EMA 趋势排列
  2. RSI 动量偏向
  3. MACD 方向强弱
  4. 布林带位置
  5. 成交量方向（买盘/卖盘占比）
  6. 资金费率（对称阈值 ±0.07% 修复）
  7. LSR 多空比（连续逆映射）
- **状态自适应权重**：趋势模式（ADX≥22）→ 顺势因子主导；震荡模式（ADX<22）→ 均值回归因子主导
- **每个因子权重可调**：拖拽滑块实时调整
- **资金费率修复**：对称阈值 ±0.07%，消除原版系统性偏多
- **时间分布预测**：5 分钟 / 15 分钟概率分布，含 95% 置信区间和期望值

### 📈 K 线图
- **5 种时间周期**：5m / 15m / 1H / 4H / 1D
- **可调 K 线根数**：60 / 100 / 200
- **K 线叠加指标**：布林带、肯特纳通道、EMA（9/21/50）
- **十字光标**：悬停显示 OHLC 价格详情
- **成交量柱状图**：红绿着色 + 均量线 + 放量高亮（橙色）

### 📡 技术指标
实时计算的指标面板，每项包含数值、进度条和标签：
- RSI(14) 超买超卖判定
- RSI(6) 短线极端信号
- MACD 多空区域
- 布林带位置百分比
- BB 宽度（波动率压缩判定）
- ATR 波动率水平
- HV 历史波动率
- ADX 趋势强度
- 随机指标 K
- 量能比（放量/缩量判定）
- EMA 多头/空头排列

极端信号时底部显示强化提示条。

### 🌍 市场状态机（6 种）
基于多维度数据自动识别市场状态：

| 状态 | 触发条件 |
|------|----------|
| 🚀 主升浪加速 | 量能暴涨 + ADX>25 + 斜率>0.5% |
| 💣 主跌浪加速 | 量能暴涨 + ADX>25 + 斜率<-0.5% |
| 🎯 突破前积累 | 布林大幅收缩 + 量能未放大 |
| 🌅 趋势衰竭 | 趋势延续但量能萎缩 |
| 🌊 高波动震荡（洗盘） | ATR>3% 但无方向 |
| 😴 低波动震荡（积累） | ATR偏低 + 窄幅震荡 |

### ⚡ 策略信号中心（7 种策略）

| 策略 | 核心指标 | 独立参数 |
|------|----------|----------|
| 趋势跟踪 | EMA 排列 + MACD + ADX | EMA快/慢周期、MACD参数、ADX阈值 |
| 均值回归 | RSI 超买超卖 + 布林带 + KD | RSI周期/阈值、布林周期/σ、KD周期 |
| 突破策略 | 唐奇安通道 + 成交量 + ATR | 唐奇安周期、量能倍数、ATR止损乘数、假突破过滤 |
| 波动率策略 | BB Width + ATR 收缩 + HV | BB宽度阈值、ATR压缩周期、压缩确认根数 |
| 网格策略 | ADX + ATR 震荡判定 | 网格数量、区间上下轨、单格利润、ATR上限 |
| 单边策略 | ADX + 量能 + EMA + RSI | ADX确认阈值、量能倍数、衰竭RSI阈值 |
| 箱体策略 | 唐奇安箱体 + 量能 + RSI | 箱体周期/高度、突破量能倍数、边界容差 |

所有策略参数均可独立调节，信号附带方向（做多/做空/观察）、强度等级、详细说明和止损建议。

### 📋 策略回测
- 7 种策略独立回测
- 可选周期：7 天 / 30 天 / 90 天
- 可选 K 线粒度：日线 / 4 小时 / 1 小时 / 15 分钟 / 5 分钟
- 可选初始资金：$1K / $10K / $100K
- 参数自动同步策略中心当前设置
- 回测结果包含：
  - 总收益率、胜率、盈亏比、最大回撤、夏普比率、交易次数
  - K 线图（含买卖标记）
  - 资产曲线 vs 买入持有
  - 最近 20 笔交易记录

### 🛡️ 仓位盯盘 & 防爆仓预警
- 输入开仓价格、方向、杠杆、保证金
- 实时计算：爆仓价格、爆仓距离%、当前盈亏
- 三级预警：绿（>8% 安全）/ 黄（4-8% 警告）/ 红（<4% 危险）+ 边框脉冲动画
- **模拟加仓计算**：均价、综合杠杆、强平距离变化
- **开仓策略标注**：标记本次开仓参考了哪些策略
- **完整交易日志**：自动记录开平仓、盈亏统计、胜率/盈亏比
- 数据通过 localStorage 持久化，刷新不丢失

### 🎯 期权市场
- 从 Deribit API 获取 BTC 期权数据
- 看跌/看涨比（Put/Call Ratio，含 OI 和 Volume 两个维度）
- 隐含波动率均值
- 配合当前价格方向给出市场情绪研判

### 🌍 世界局势 & 宏观风险
内置宏观风险模块，展示当前地缘政治、经济政策、市场情绪等维度评估。

### 📰 新闻资讯
多源容错新闻聚合，含自动情感倾向识别（利好/利空/中性）。

### 🤖 DeepSeek AI 分析
- 输入 DeepSeek API Key 后调用 AI 进行深度市场分析
- 自动填充当前所有市场数据到提示词
- 支持 deepseek-chat / deepseek-reasoner 两种模型
- Key 仅在前端本地使用，不经过任何第三方

## 技术特性

- **纯前端**：零后端依赖，浏览器直接打开即可运行
- **API 多源容错**：OKX → Binance → 模拟数据（K 线三级降级）
- **无依赖**：仅从 CDN 加载 Chart.js（用于回测资产曲线图），K 线图使用原生 Canvas 渲染
- **暗色主题**：专业暗色 UI，适合长时间盯盘
- **响应式布局**：自适应网格 + 滚动条美化
- **数据持久化**：交易日志存于 localStorage
- **公式透明**：所有概率模型的计算公式均在前端代码中公开可见

## 使用方法

1. 用浏览器打开 `btc_analysis_v7.html`
2. 页面自动从 OKX API 加载实时数据
3. 在「多空概率计算器」中调节因子权重，观察概率变化
4. 切换到不同策略标签页，查看当前信号
5. 在「策略回测」中选择策略和周期，点击运行
6. 在「仓位盯盘」中输入持仓参数，开始盯盘
7. 可选：输入 DeepSeek API Key 获取 AI 分析
